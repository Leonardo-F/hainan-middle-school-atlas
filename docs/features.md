# 功能与实现 · 海南中学校园图志

> 面向想了解「这个页面能做什么、怎么实现的」的读者。开发约定与目录见 [contributing.md](contributing.md)；精度边界见 [accuracy.md](accuracy.md)。

## 漫游与取景

- 拖动旋转、滚轮/双指缩放、右键/双指平移；桌面端带自定义光标。
- 点击建筑、编号地标或索引条目，相机飞向对应建筑并打开图志。
- 自动导览按固定顺序巡游 8 处校园地景；`T` / `O` / `F` 切换导览、总览、全屏。
- 桌面快捷键：数字键 `1`–`8` 定位地标，`Esc` 关闭图志或暂停导览。

## 图志与索引

- 20 处地景统一收录进「地景索引」，含立面示意图、沿革、观察要点与取景参数。
- 场景编号默认隐藏，选中地标后只显示当前项的编号与名称。
- 小地图（校园总平面）可点击定位；地标卡片支持「上一处 / 下一处」连续阅读。
- 地景覆盖：校门、主教学楼、凤栖堂、衍林堂、科学馆、体育馆、运动场、办公楼、3 号教学楼、艺术楼、曲水流觞、学园、图书馆、南门、主席台与看台、百年榄仁树、太湖石「虎踞龙盘」、夫子像、「春风化雨」铜像、手形雕塑。

## 昼夜与天气

- 日照滑杆 06:00–20:48 连续调整太阳高度、色温、天空渐变、窗光、路灯与雾。
- 六种天气：晴 / 小雨 / 暴雨 / 台风 / 雷雨 / 下雪，均为纯前端程序化效果（雨幕、斜雨、闪电、雪花、地面积雪），并与当前时刻联动。
- 学生行为随天气变化：雨天部分撑伞、其余跑到最近避雨点；雪天不打伞、略减速。

## 自动巡游影片

- 约 77 秒、28 段的电影式巡游：高空入校 → 北门 → 凤栖堂外景 → 主教学楼门厅/走廊/教室 → 图书馆内外 → 科学馆/艺术楼 → 体育馆/看台/运动场 → 升空收尾。
- 带遮幅、片名、中英字幕与进度条；可「录制并下载」为 WebM。
- `?film=1` 直接播放，`?film=1&record=1` 无人值守自动出片；README 巡游样片见 `assets/preview/campus-tour.mp4`。

## 建筑与室内

- 校门、主教学楼、凤栖堂、衍林堂四座重点建筑为独立米制模块（`js/landmarks/`），按照片与官方资料复原形制、比例、屋顶、门窗、匾额与庭前雕塑。
- 两处低模写意室内：主教学楼首层门厅/走廊/教室、图书馆阅览室，用于影片穿行与近距离观察（凤栖堂厅堂旧室内已按用户反馈移除）。
- 学生与校服：步行路线 + 跑道 16 名跑步学生；校服按公开的夏季运动套装还原。

## 程序化渲染

- **零外部素材**：屋瓦、铺地、立面、匾额、跑道、树冠、旗帜均由 Canvas 2D 程序化生成，运行时无第三方网络请求。
- **材质细节**：近景材质由 albedo 亮度生成法线 + 粗糙度贴图（砖缝、瓦垄、铺地拼缝），同参数共享缓存，`?detail=off` 可关闭对比。
- **环境反射**：用程序化天空烘 PMREM 环境贴图，只给金属/玻璃/水面挂 `envMap`，保持纸感的同时让银穹顶、玻璃幕墙有真实反射；`?env=off` 可 A/B。
- **光照**：半球光 + 太阳（PCFSoft 阴影，按需更新）+ 月/补光；ACES Filmic 色调映射；夜间窗光与路灯以自发光 + 点光实现。

## 电子宠物「海海」

- 校园吉祥物「海海」默认关闭，点控制条「海海」后出现：蓝色身体、白下脸与肚皮、校徽棒球帽、白色小书包，全部由基础几何 + Canvas 贴图生成，零外部素材。
- 三条状态：饱腹、精力、亲密。按真实时间衰减（离线也算），睡觉回复精力；状态决定表情与语气。
- 互动：点画面里的海海或面板按钮可抚摸、喂食、睡觉、隐藏；按住海海可拖到任意位置，位置存本机；面板滑块/↻ 按钮或 Shift+拖动可做 360° 旋转，Shift+双击回正；脚底柔光投影让站位更稳。
- 隐藏后 dock 按钮变成「召回」，右下角出现「召回海海」浮标，点其中一个即可恢复。
- dock 的「海海」按钮开启宠物并打开面板；播放巡游影片时自动隐藏；`?pet=on` 强制显示、`?pet=off` 关闭、`?pet=reset` 重置。
- 技术构成、确定性与后续玩法见 [pet.md](pet.md)。

## 高三拾伍班（室内）

- 主教学楼**顶楼、面向大门左侧**的教室独立成第 21 处图志（`?spot=classroom`）。
- 室内按用户照片与现场描述重排：储物柜那一墙是教室的后边，课桌顺时针旋转 90° 面向 x1 前墙的黑板；后墙三层储物柜、海洋主题壁画、长方体木书柜（正面中央三角形装饰）、绿色窗帘、书堆/布袋/玩偶与吊扇保留。
- 室内采用**定点环视**：相机固定在房间内的站位，拖动画面可 360° 环顾四周，不绕轨道、不穿墙；讲台/黑板与储物柜/壁画在转身之间都能看到。

## 学生视角

- 直接单击画面里的任意一位同学，即可切换到他的第一人称视角；也可以按控制条「学生」进入选人模式（学生暂停行走，点击有约 44px 容差，更方便点选）。
- 相机高度约 1.7 m，跟随学生的行走/避雨/跑步状态与朝向；`Esc` 或「退出学生视角」返回进入前的机位。
- 左上角只显示「同学01」这样的编号，不再带班级名；学生之间保持间距，路线交叉时自动错开，并绕开太湖石、石桌石凳与古树。
- 「换一位同学」不再进入点选模式，而是随机换到另一位不同的同学；学生走路偶尔会离开固定回路，随机走一段再回路线，不再是整齐的固定往返。
- 学生点选使用加大的不可见点击代理，并做建筑遮挡判断，不会隔着墙选中同学；行走、打伞、躲雨、跑道跑步的学生都可选。

## 图志实景照片

- 21 处地景的图志卡都有一张实景照片，点击建筑后出现在左侧标题、立面示意与摘要下方。
- 照片标注「实景 / SITE PHOTO」或「参考 / REFERENCE」；每张都带图注与来源链接。参考图用于暂无公开实拍的同类/同片区对象（如南门以同款北门参考）。
- 来源包括海南中学官网 2013 校园风景图集、B 站百年校庆影像/航拍、用户提供的教室与主教学楼航拍照；照片与单文件版一起内联，离线可看。

## 响应式与分享

- 桌面端环景式图志界面；手机端横向地标条、编号地标与底部抽屉，并自动重新取景。
- URL 参数：`?campus=`、`?spot=`、`?hour=`、`?view=top`、`?weather=`、`?film=`，详见 [README](../README.md#快速开始)。
- 开发参数：`?still=1&nointro=1`（视觉回归固定帧）、`?env=off`、`?detail=off`。
