# 模型与功能设计注记 · 府城校园图志

本文件承接原 README「项目特征」一节，记录当前模型的建筑处理、系统设计与已知写意项。**精度与证据判定见 [accuracy.md](accuracy.md)**；变更时间线见 [changelog.md](changelog.md)。

> 一句话定位：校园总平面参考 OpenStreetMap 轮廓与公开影像整理；重点建筑依据公开照片与官方资料复原形制与尺度（写意模型，非测绘），其余体量 / 立面为设计推演。**非测绘成果，不用于导航或空间决策。**

---

## 总平面与场地

- **总平面**：运动场在西侧，体育馆在运动场东南侧；教学组团沿校园中部和东侧展开；凤栖堂靠近北门（西北侧历史校门），衍林堂沿北界东段，南门在南界。
- **单一主轴**：校门至主教学楼正门只保留一条直达主干道，不经过凤栖堂，也不再铺设交叉支路；凤栖堂、衍林堂前另有一条横向主路。
- **门前清理**：校门外的城市道路与北侧门前铺地不再展示，只保留校园内部主路、行道树和围墙。
- **物理检查**：对建筑体块、檐口与相邻建筑做过一次性二维轮廓与间距自检（关键净距记录在代码注释，自检脚本未随仓库分发）。此前被当作附属块跳过的三处 OSM 多边形（1165596684 / 1165596685 / 1165596686，数据未删）经卫星叠图与 OSM 邻接关系复核，确认是**连廊本体**，现已按 OSM 多边形重建为开敞柱廊；科学馆与 3 号教学楼保留明确缝隙，艺术楼、曲水流觞、手形雕塑、看台、道路均不穿过其他建筑。
- **可读的体量**：教学楼、科学馆、体育馆与生活建筑按 OSM 轮廓和实际方位布置。

## 四座重点建筑

校门、主教学楼、凤栖堂、衍林堂均为独立模块（`js/landmarks/*.js`），依据公开照片与官方资料按形制与米制尺度复原（写意模型，不保证与实物逐处一致）：

- **校门**：四柱三间、三段曲面绿瓦顶、右读「海南中學」门额、四只石狮、围墙返段。
- **主教学楼**（原 1 号教学楼）：五层长楼、五段红瓦屋顶、深色石材「1923」门架、红色抱厦、楼前太湖石。
- **凤栖堂**：两重绿琉璃瓦檐、六柱红金檐廊、黄色透花栏板、夫子像。
- **衍林堂**：两层白墙、绿色曲面双坡顶与白色山墙、腰檐、红木格窗、露台红栏、「春风化雨」群像。

四座建筑按真实尺度以「米」建模，`finalize()` 统一换算到场景单位，并按材质合并网格控制开销。

参考照片（不随页面分发，仅作复原依据）：校门与轴线照片来自 Wikimedia Commons（CC0，2013 年，Anna Frodesiak）；凤栖堂、衍林堂、主教学楼照片来自学校官网公开页面与用户提供的航拍照，页面内不复用这些照片。

## 教学组团

- **教学组团细节**：主教学楼补上中央塔楼、两端红瓦亭与入口台阶；办公楼补上连续柱廊；主教学楼与 3 号教学楼之间补上手形雕塑、学园、连廊与庭院绿化。细节参考海南中学官方校园图集。
- **连廊与学园**：主教学楼↔办公楼两端各一条两层开敞连廊，办公楼↔科学馆在靠体育馆一侧另有一条窄连廊（接科学馆朝校门一侧的突出体块）；两楼之间是「学园」——大面积浅色铺地，中央一方写有「学」字的方场，没有建筑与乔木（按用户 2026-11 的现场描述修正；铺地用项目程序化贴图）。
- **科学馆与艺术楼**：科学馆改用其真实 OSM 多边形轮廓并轻微内收，与 3 号教学楼留出清晰缝隙；3 号教学楼也改用真实轮廓并补上真实轮廓上的横向窗带、屋顶楼梯间与红瓦檐口；艺术楼放大后移到科学馆后侧、更靠近东南侧的空隙，避免与科学馆、3 号教学楼穿插。
- **艺术楼**：体量放大并略向东南平移（21×9.5 场景单位，约 42×19 m；6 层、约 23.5 m），曲水流觞随之让开；白色水平饰带与红瓦坡顶保留，**正门与门廊改朝西北的北门一侧**。不同公开资料对艺术楼层数有出入（另有「地上 3 层、最高 22.85 m」的招标口径），模型按 2015 年资料的写意体量呈现。
- **曲水流觞**：艺术楼旁新增蜿蜒水庭，包含五段水池、石岸、小石桥、立石题名，以及芦苇与睡莲。

## 体育馆与运动场

- **体育馆体量**：按用户 2026-11 反馈，去掉了上一版屋面上的「半球形」构件（5 道并排半圆筒拱、端部半圆拱面与白色拱肋），改为**长方体平屋面**：浅色大跨墙身、通长横向玻璃带、平屋面 + 女儿墙 + 屋面楼梯间/设备，西南长边保留入口雨棚、台阶、外挂楼梯与「胡文虎体育馆」门额。调研影像中曾出现类似筒拱的拱肋，但用户明确要求去掉，故按写意长方体呈现。
- **操场主席台与看台**：跑道东南直道、体育馆与跑道之间是一条**长直阶梯看台**（10 级，下段蓝色、上段黄色，长约 60 m 为场景推演），上方为白色薄顶棚 + 细柱 + 绿藤；**主席台居中**，长条顶棚在主席台两侧断开、不再压住主席台（白色弧形顶、红/蓝座椅、红色背景板）。**只保留一根国旗旗杆**（校旗已按 2026-11 反馈去除），立在主席台前缘外侧（位置无影像证据，为写意布置）。看台位置以卫星叠图为参考，因校园红线约束东移约 16 m，最终位置为推演；形制参照 2023 年校运会影像；看台与体育馆同侧。
- **排球场**：凤栖堂与校门之间的现有排球场位置正确，保留 1 片；官方 1:500 总平面显示该区域历史上有多片球场/活动场地，现存数量待核（OSM 现存 1 片）。

## 主要地景与雕塑

- **图书馆**：新增三层白瓷砖图书馆（绿色玻璃拱形门斗、宽台阶、屋顶银色穹顶圆塔）；该建筑未见于 OSM 轮廓，位置与轮廓为依据 2023 年校庆影像与卫星图推测的写意位置（置信度中低，非测绘；候选点与落地相差约 10 场景单位）。
- **南门**：复用北门模块（四柱三间、三段绿瓦顶）但**不设石狮**，按围墙缺口缩至约 22 m 宽（宽度据研究推定）；2015-05-30 竣工（官方大事记）。南门无独立影像可核对，形制为参照北门的写意推定。
- **女生宿舍**：位置尚未确认。2026-11 曾按推测位置重建一栋，但用户指出位置不对，现已**先删除**该体量；待确认真实位置后再补建（东侧原 1444498450 恢复为未命名体块）。
- **食堂**：卫星上 OSM 体育馆正南为 OSM 未收录小楼与校内菜地，食堂更可能在东侧宿舍区，故**不标注、不建体量**。
- **初中部**：官方 2023 年新生指南确认初一在**初中部教学楼**报到；初中部是独立校区（位于高中部南侧，约 0.3–0.6 km，不同底图偏移有出入），本图志**未绘制**。按用户 2026-11 反馈，未绘制前不在校区切换器中展示，只在说明对话框中标注「本图志仅绘制高中部；初中部尚未绘制」。
- **百年古树**：与「虎踞龙盘」太湖石同一排，位于校门左侧、主楼右前方；按巨大榕状树冠、垂落气根表现，树下设置石桌与四个石凳。
- **细节校正**：校门后不设第二道牌坊；衍林堂前为「春风化雨」钟衍林与学生铜像；凤栖堂前为夫子像，庭院使用灰色石板铺地；主教学楼前广场置「虎踞龙盘」太湖石；主教学楼与办公楼之间为「学园」。
- **教学楼命名**：按用户 2026-11 反馈，1 号教学楼改为**主教学楼**、2 号教学楼改为**办公楼**、第 3 教学楼改为**3号教学楼**；地标、索引、小地图与场景标签同步。

## 人物与氛围

- **学生与校服**：在主要建筑、庭院、校门附近布置男女学生步行路线，并在运动场红色跑道上安排 16 名男女学生跑步；校服按学校公开的夏季运动套装还原为白色短袖、青绿色领口/袖口/裤侧条与白鞋，少量学生着白色正装衬衫、深色西裤/白裙。参考：[海南中学校服选购说明](http://www.jlgjzx.com/haizhong/2026-08/03/article_2026080316203796381.html)。
- **天气系统**：日照面板下方新增天气滑杆「晴 / 小雨 / 暴雨 / 台风 / 雷雨 / 下雪」；雨幕、暴雨、台风斜雨、雷雨闪电、雪天雪花与地面积雪均为纯前端程序化效果，并保持昼夜时刻联动。
- **学生天气行为**：下雨时约一半步行学生撑伞继续走、其余（含跑道跑步学生）小跑到最近避雨点（主教学楼门廊、办公楼连廊、科学馆入口、凤栖堂/衍林堂檐廊、图书馆门廊、体育馆雨棚、主席台顶棚）待机，雨停后回到原路线；雪天不打伞、略减速；所有学生逐帧避让全部建筑多边形（23 栋）与校园红线，不再穿模。

## 叙事与交互

- **统一索引**：所有名称统一收进「地景索引」；主教学楼、3号教学楼、艺术楼、曲水流觞、手形雕塑、学园、南门、图书馆等均可在索引中点开。场景编号默认隐藏，点击建筑后才显示当前项的编号与名称。虎踞龙盘太湖石、凤栖堂夫子像、衍林堂「春风化雨」铜像也作为独立雕塑条目收录。
- **编号默认隐藏**：场景中的建筑编号标记默认隐藏，点击建筑、索引或导览时只显示当前选中地标的编号与名称，关闭图志后再次隐藏。
- **轻量交互叙事**：地景索引、三维编号标记、小地图、建筑信息卡、自动导览与可访问的移动端抽屉。
- **响应式**：桌面端为环景式图志界面；手机端使用横向地标滑动条、编号地标与底部信息抽屉，并自动重新取景。

## 室内、影片与渲染

- **室内场景**：主教学楼首层（门厅、走廊、教室，含黑板/课桌椅/窗带/吊灯）、图书馆首层阅览室（书架、阅览长桌、台灯、高窗）、凤栖堂厅堂（红柱、梁架、匾额、条案、展柜、灯笼）；均为低模写意室内，用于自动影片穿行和近距离观察。
- **自动巡游影片**：点击底部「影片」进入约 85 秒的电影式巡游（30 段：高空入校 → 北门 → 凤栖堂内外 → 主教学楼门厅/走廊/教室 → 图书馆内外 → 科学馆/艺术楼 → 体育馆/看台/运动场 → 升空收尾），带遮幅、片名、中英字幕与进度条；播放中可「录制并下载」为 WebM，也可用 `?film=1&record=1` 无人值守自动出片。样片见 `assets/preview/campus-tour.mp4`。
- **程序化细节**：屋瓦、铺地、立面窗格、匾额、跑道、地形材质均由 Canvas 实时绘制，没有外部贴图依赖。
- **昼夜研究**：太阳角度、天空渐变、长阴影、窗光与路灯随时刻连续变化；阴影贴图仅在时刻变化时重新计算。

## 已知写意 / 未解决项

以下均无足够公开证据，模型中的处理为写意，不等同于实测，逐条判定见 [accuracy.md](accuracy.md)。另外，固定 1 场景单位 = 2 米是场景比例，不等于测绘精度：

- 国旗旗杆的真实位置与高度；
- 南门实拍（形制参照北门推定）；
- 食堂位置与「体育馆—食堂—初中部」道路；
- 看台精确长度；
- 艺术楼真实位置与层数（公开口径存在出入）；
- 图书馆真实位置与馆舍信息（置信度中低）；
- 女生宿舍位置（已删除体量，待确认）；
- 初中部（独立校区，未绘制）。

> 如需用于正式宣传、导览或校园空间展示，建议以学校官方资料、实测图纸和授权影像进一步校核。
