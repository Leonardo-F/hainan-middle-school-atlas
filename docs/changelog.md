## 2026-11-12 — 许可证、文档与工程化

- **许可证**：加入 [MIT LICENSE](../LICENSE)，Copyright © 2026 Gaoming Fan（范高铭）；OSM 数据仍按 ODbL 1.0、字体按 SIL OFL 1.1 分发。
- **文档整理**：README 重构为展示型入口（图集 → 快速开始 → 工作流 → 精度 → 文档索引）；新增 [accuracy.md](accuracy.md)、[visual-regression.md](visual-regression.md)、[contributing.md](contributing.md)、本文件与 [design-notes.md](design-notes.md)。
- **视觉回归 harness**：新增 `tools/shot.mjs`（Playwright 驱动本机 Chrome，按固定机位截图并与基准逐像素比较）、`tools/imagediff.mjs`、`tools/shots.mjs`（9 个机位）；新增 `npm run shots` / `npm run shots:update`，基准图不入库（`.gitignore`）。详见 [visual-regression.md](visual-regression.md)。
- **环境反射（PMREM）**：用程序化天空烘一张 PMREM 环境贴图，仅给金属 / 玻璃 / 水面材质挂 `envMap`，替代此前「压 metalness + 自发光」的临时方案；可用 `?env=off`、`?envint=`、`?envmat=`、`?envsel=off` 做 A/B 对比。
- **调研入库**：[ai-generated-3d-games.md](ai-generated-3d-games.md) 的「AI 一次生成可玩 3D 网页游戏」技术拆解与可用性评估纳入仓库，其中记录的 GTAO/PMREM/视觉回归清单即本轮改动的来源之一。
- **材质细节**：新增 `applyDetailMaps()`（`js/textures.js`）：把程序化 albedo 的亮度当高度场，生成法线 + 粗糙度贴图（砖缝、瓦垄、铺地拼缝、抹灰颗粒），同参数共享缓存、默认 256²；`?detail=off` 可做 A/B。仅作用于近景材质，保持远景纸感与移动端显存预算。
- **README 再精简**：新增 [features.md](features.md)（功能与实现）与 [structure.md](structure.md)（完整目录）；README 只保留概览、图集、快速开始、文档入口、目录速览与许可证；**GitHub Pages 在线地址固定放在标题下方**，发布说明见 [contributing.md](contributing.md#发布github-pages)。

## 2026-11-09 — 室内、巡游影片、天气与学生行为

- **室内场景**：新增主教学楼首层（门厅、走廊、教室）、图书馆首层阅览室、凤栖堂厅堂三处低模写意室内与相机机位，用于影片穿行与近距离观察。
- **自动巡游影片**：约 85 秒电影式巡游（30 段，高空入校 → 北门 → 凤栖堂内外 → 主教学楼 → 图书馆 → 科学馆/艺术楼 → 体育馆/看台/运动场 → 升空收尾），带遮幅、片名、中英字幕与进度条；支持录制并下载 WebM，`?film=1&record=1` 可无人值守自动出片；样片 `assets/preview/campus-tour.mp4`。
- **天气系统**：日照面板下方新增天气滑杆「晴 / 小雨 / 暴雨 / 台风 / 雷雨 / 下雪」；雨幕、斜雨、闪电、雪花与地面积雪均为纯前端程序化效果，并与昼夜时刻联动。
- **学生天气行为**：雨天约一半步行学生撑伞继续走、其余（含跑道跑步学生）小跑到最近避雨点待机，雨停后归队；雪天不打伞、略减速；所有学生逐帧避让全部建筑多边形（23 栋）与校园红线。
- **学生与校服**：在主要建筑、庭院、校门附近布置男女学生步行路线，运动场红色跑道安排 16 名学生跑步；校服按公开的夏季运动套装还原（白色短袖、青绿色领口/袖口/裤侧条、白鞋），少量学生着正装衬衫。
- **图书馆与校园修正**：新增三层白瓷砖图书馆（绿色玻璃拱形门斗、宽台阶、屋顶银色穹顶圆塔）；同步完成艺术楼体量、南门、连廊、学园等 2026-11 修正（逐项依据见下节）。详见 [design-notes.md](design-notes.md)。

## 2026-11-08 — 初版与四座重点建筑

- **初版**：基于 Three.js r169 的交互三维校园上线，含总平面、地景索引、图志信息卡、小地图、昼夜与自动导览。
- **四座重点建筑复原**：校门、主教学楼（原 1 号教学楼）、凤栖堂、衍林堂独立为米制模块（`js/landmarks/`），依据公开照片与官方资料复原形制、比例、屋顶、门窗、匾额与庭前雕塑（写意模型，非测绘）；共享中式构件库 `js/landmarks/parts.js`。
- **多校区架构准备**：数据层拆为 `js/campuses.js`（校区注册表）/ `js/data.js`（内容层）/ `js/site.js`（空间层），场景构建器 `js/campus-accurate.js` 接受 `{campus, site, landmarks, theme}` 并提供 `dispose()`；新增校区步骤见 [campuses.md](campuses.md)。

## 2026-11 修正与证据（迁移自 README）

本轮修正依据 **OpenStreetMap 轮廓（ODbL）**、公开地图截图与公开影像/航拍做人工比对（卫星底图与抽帧不随仓库分发，不构成可复现证据链），逐项核对后重做：

| 修正项 | 结论 / 做法 | 依据与置信度 |
| --- | --- | --- |
| 国旗、校旗 | 仅保留一根国旗旗杆（校旗已按 2026-11 反馈去除）；位置/高度无影像证据，为写意 | 无旗杆影像证据；位置为写意 |
